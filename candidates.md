# Funniest Time Machine Warning Label — Candidates

Bounty: Funniest Time Machine Warning Label (u-eager-stork-81-9647-funniest-time-machine-warning-f8add151), $2 winner-takes-all, blind round R1 25 Nov 09:53 WIB, closes 26 Nov 21:15 WIB.

## Judging criteria (in priority order)

1. Truly a warning label for a time machine.
2. Turns a real time-travel danger (paradox, doubles, stranded ancestors, etc.) into a joke, not just naming it flatly.
3. Surprise saved for the last few words.
4. Deadpan — written like an official safety notice, so the joke contrasts with official calm.
5. No wasted words inside 120 characters; every phrase must work.

## Saturation to avoid (676 entries already in)

"Do not meet yourself" / "meet yourself" (51), "grandfather" (75), "warranty" (33), "do not ..." openings (178), flat "paradox" mentions (24), "past self" (29), "ancestor" (23), "butterfly" (7), "dinosaur" (5), "refund" (8). All candidates below avoid these tropes and instead use fresh angles: return logistics, baggage/customs, fuel, manuals, queues, lost property, seatbelts.

Character counts were counted twice (word-length sum + spaces, and running total). All counts include spaces and punctuation.
