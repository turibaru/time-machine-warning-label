# Claim It Yesterday — Time Machine Warning Label

A deadpan transit warning for a time machine: your luggage may arrive before you do — so claim it yesterday, at Gate 12.

Entry for the make.fun bounty **Funniest Time Machine Warning Label** (winner-takes-all, $2). The label is 74 characters: a real temporal hazard (belongings separated across time) turned into a joke, with the surprise saved for the last three words, written in a flat official CAUTION-notice voice.

## Entry

> CAUTION: Luggage may arrive before you do. Claim it yesterday, at Gate 12.

## How it works

`main.ts` reads `entry.txt` from this repo and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`. It exits non-zero if the label is not 1–120 characters on a single line, or if writing the output fails. Run with `node main.ts`.
